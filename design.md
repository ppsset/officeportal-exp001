# WAG Portal - Design Style Guide

## Design Philosophy

### Color Palette
- **Primary**: Deep charcoal (#2D3748) and warm white (#FAFAFA) for maximum contrast and readability
- **Secondary**: Muted steel blue (#4A5568) for subtle accents and borders
- **Accent**: Soft amber (#D69E2E) for active states and important highlights
- **Status Colors**: 
  - Success: Muted sage green (#38A169)
  - Warning: Soft orange (#DD6B20)
  - Error: Muted red (#E53E3E)
  - Info: Soft blue (#3182CE)

### Typography
- **Display Font**: "Inter" - Clean, modern sans-serif for headings and navigation
- **Body Font**: "Inter" - Consistent typography throughout for professional appearance
- **Monospace**: "JetBrains Mono" - For technical data, code snippets, and measurements

### Visual Language
- **Minimalist Professional**: Clean lines, generous white space, and purposeful design elements
- **Engineering Precision**: Grid-based layouts reflecting the technical nature of MEP work
- **Data-Driven**: Clear hierarchy and organization suitable for technical information display
- **Accessibility First**: High contrast ratios and clear visual indicators

## Visual Effects and Styling

### Used Libraries
- **Anime.js**: Subtle fade-in animations for dashboard cards and form elements
- **ECharts.js**: Professional data visualization for wellbeing monitoring and analytics
- **Splide.js**: Smooth carousel for image galleries in tech knowledge module
- **Matter.js**: Physics-based interactions for engaging UI elements (minimal usage)
- **p5.js**: Custom data visualization and interactive graphics for monitoring systems

### Background and Layout
- **Solid Background**: Consistent warm white (#FAFAFA) throughout all pages
- **Grid System**: CSS Grid and Flexbox for precise, responsive layouts
- **Card-Based Design**: Elevated cards with subtle shadows for content organization
- **Sidebar Navigation**: Fixed left sidebar with collapsible functionality

### Interactive Elements
- **Hover States**: Subtle color transitions and gentle scale effects
- **Button Design**: Rounded corners with clear visual hierarchy
- **Form Elements**: Clean, modern inputs with focus states
- **Loading States**: Professional spinners and progress indicators

### Header Effects
- **Minimal Animation**: Subtle fade-in for dashboard statistics
- **Status Indicators**: Color-coded badges and progress bars
- **Responsive Typography**: Fluid text sizing for different screen dimensions

### Data Visualization Style
- **Monochromatic Charts**: Using variations of the primary color palette
- **Clean Axes**: Minimal grid lines and clear labeling
- **Interactive Tooltips**: Contextual information on hover
- **Real-Time Updates**: Smooth transitions for live data changes

### Mobile Responsiveness
- **Bottom Navigation**: Mobile-optimized tab bar for easy thumb navigation
- **Collapsible Sidebar**: Transforms to overlay menu on smaller screens
- **Touch-Friendly**: Adequate tap targets and gesture support
- **Simplified Layouts**: Streamlined content hierarchy for mobile viewing

### Professional Aesthetics
- **Consistent Spacing**: 8px base unit for all margins and padding
- **Subtle Shadows**: Soft drop shadows for depth without distraction
- **Clean Borders**: 1px solid borders in muted colors
- **Professional Icons**: Outline-style icons for clarity and consistency

### Accessibility Features
- **High Contrast**: 4.5:1 minimum contrast ratio for all text
- **Focus Indicators**: Clear keyboard navigation support
- **Screen Reader Support**: Proper ARIA labels and semantic HTML
- **Color Independence**: Information conveyed through multiple visual cues

This design approach ensures the WAG Portal maintains a professional, engineering-focused aesthetic while remaining user-friendly and accessible across all devices and user types.
